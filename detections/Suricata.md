# Suricata IDS Detection

## 📌 Objective

The objective of this detection is to monitor network traffic using Suricata IDS and forward security events to Wazuh for analysis and investigation.

The integration enables real-time detection of suspicious network activity within the SOC environment.

---

# 🖥️ Environment

- Windows 11 Host
- Docker Desktop
- Wazuh Manager 4.12
- Ubuntu 24.04
- Wazuh Agent
- Suricata IDS
- Kali Linux

---

# 🛠️ Configuration

Suricata was configured to generate events in JSON format.

The Wazuh Agent monitors:

```text
/var/log/suricata/eve.json
```

Configuration added to `ossec.conf`:

```xml
<localfile>
  <log_format>json</log_format>
  <location>/var/log/suricata/eve.json</location>
</localfile>
```

After configuration, the Wazuh Agent service was restarted.

```bash
sudo systemctl restart wazuh-agent
```

---

# 🚨 Detection

Suricata generated IDS alerts which were successfully collected and displayed in the Wazuh Dashboard.

Examples of monitored events include:

- Network anomalies
- TCP events
- IDS alerts
- Security events
