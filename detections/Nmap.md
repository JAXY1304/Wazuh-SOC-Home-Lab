# Nmap Detection

## Objective

Detect network reconnaissance and service enumeration activity generated by Nmap against the Ubuntu endpoint using Wazuh.

## Lab Environment

| Component | Details |
|---|---|
| Attack Machine | Kali Linux |
| Target | Ubuntu-01 |
| Target IP | `192.168.1.196` |
| Tool | Nmap |
| SIEM | Wazuh 4.12.0 |

## Attack Simulation

A controlled Nmap network reconnaissance test was performed from the Kali Linux system against the Ubuntu endpoint.

The objective was to identify exposed services and demonstrate how network reconnaissance activity can be monitored in a SOC environment.
